# Cyber Security Awareness (for small businesses)

Free, plain-English cyber security resources to help small businesses — and their
staff — know **what to look out for** and **what to do**. No jargon, UK-focused,
built on guidance from the UK's **NCSC** (National Cyber Security Centre) and
**Action Fraud**.

👉 **Read it online:** once GitHub Pages is on (below), it's at
`https://simonsk19-maker.github.io/cyber-security-awareness/`

## What's inside

**Topic guides** (`guides/`) — short reads, each also prints to one or two pages:
- 📧 Spotting phishing emails & texts
- 🔑 Passwords & 2-factor login
- 💷 Invoice & impersonation fraud
- 🗄️ Ransomware & backups
- 💻 Devices, updates & antivirus
- 📶 Remote working & public Wi-Fi
- 🚨 If something goes wrong (step-by-step + UK reporting)

**Printable one-pagers** (`printables/`):
- ⭐ Top 10 quick wins (poster)
- ✅ Staff checklist (everyday habits + new-starter list)

Every page has a **Print / Save PDF** button, so you can pin them up or add them to
a staff handbook.

## Turn on the website (GitHub Pages)
1. In the repo, go to **Settings → Pages**.
2. Under **Build and deployment → Source**, pick **Deploy from a branch**.
3. Branch **main**, folder **/ (root)**, then **Save**.
4. Wait a minute, then open `https://simonsk19-maker.github.io/cyber-security-awareness/`.

## Accuracy & sources
Content reflects widely published UK guidance (NCSC *Small Business Guide* and
*Cyber Essentials*; Action Fraud reporting). It's general awareness, not formal
advice — for a tailored review, get a proper assessment. Key UK reporting:
- Scam **emails** → `report@phishing.gov.uk` · scam **texts** → `7726`
- Fraud/cyber crime → **Action Fraud 0300 123 2040** (Scotland: Police **101**)
- Data breaches → **ICO** (ico.org.uk), within 72 hours if personal data is exposed
