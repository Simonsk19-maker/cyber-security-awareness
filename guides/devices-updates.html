Devices, updates & antivirus

Keeping laptops, phones and PCs patched, protected and encrypted.

Most devices are fairly safe if they're kept up to date and have the basics switched on. These are the habits that do the heavy lifting.

Updates (patching)

  • Turn on automatic updates for Windows, macOS, phones and your main apps (browser, Office, PDF reader).
  • Replace software and devices that no longer get updates — out-of-support kit is an open door.
  • Restart when asked, so updates actually finish installing.

Protection on every device

  • Leave antivirus on (Windows Defender is fine for many small firms).
  • Turn on the firewall (on by default in Windows and macOS).
  • Encrypt laptops and phones — BitLocker on Windows Pro, FileVault on Mac, and a screen lock + encryption on phones. If a device is lost, the data stays safe.
  • Set a screen lock with a PIN/password on everything.

Phones & tablets

  • Only install apps from the official App Store / Google Play.
  • Keep them updated, and turn on Find My / Find My Device so a lost phone can be locked and wiped.
  • Use a 6-digit PIN or biometrics, not a 4-digit code.
Want a recognised baseline? The UK Government's Cyber Essentials scheme covers exactly these basics (updates, firewalls, access control, malware protection, secure settings) and can reassure your customers.
